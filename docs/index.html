Built on open Swift packages

Fianchetto is assembled from a family of standalone, reusable Swift packages. Each one is documented on its own — pick a package to dive into its guides and API.

♟️

ChessCore

A portable, Foundation-only chess core: move generation, FEN, SAN/UCI, PGN, an opening book, and a UCI engine-protocol seam.

MIT Read the docs →
🔌

BoardKit

The adapter seam between physical (BLE) chess boards and a chess engine / kernel stack — plus a board emulator and a replay/simulation harness.

MIT Read the docs →
🧠

FianchettoKit

The shared product logic behind Fianchetto: move annotation, strength and Elo estimation, tactics, repertoire and endgame drills, the game library and its backups. It links no engine and draws no pixels.

GPL-3.0 Read the docs →
🐟

SwiftStockfish

A Swift Package Manager wrapper around Stockfish 18: a clean UCI engine API and a version-aware NNUE network loader.

GPL-3.0 Read the docs →
🦀

SwiftReckless

A Swift Package Manager wrapper around the Reckless engine (Rust), in-process via a C FFI bridge, with the neural network loaded at runtime.

AGPL-3.0 Read the docs →

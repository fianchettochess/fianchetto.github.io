    estimate¶

    Turns one game's White-POV eval array — plus its clock, and optionally Maia evidence and the PGN Termination tag — into a calibrated per-game Elo performance with a confidence interval. Everything numerical is linked kit code; the command adds JSON shaping and one route label.

    stdin¶

    One JSON object per line.

    Field Type Required Default Meaning
    id String yes — echoed on the response line
    white_pov_evals [Double] yes — the annotate output array; needs at least 2 entries
    start_is_white Bool yes — which color moved at ply 0
    color String yes — "white" or "black", case-insensitive; which side is being rated
    tc_base_seconds Int or null no null base clock; null means correspondence
    tc_increment_seconds Int or null no treated as 0 per-move increment
    is_otb_classical Bool no false widens the CI by 1.5×
    maia_log_likes [Double] no absent legacy bare 11-point vector
    maia_evidence object no absent versioned evidence; takes precedence over the bare vector
    termination String no absent PGN Termination value; feeds the is_time feature

    maia_evidence has three required members:

    Member Type Meaning
    log_likes [Double] the 11-point vector
    eligible_move_count Int how many owner moves were scored
    opponent_conditioning String exactly "exact-lichess-opponent" or "neutral-lichess-1500"

    stdout¶

    Field Type Meaning
    id String the request id
    elo Double point estimate, clamped to 100…3500
    ci_low / ci_high Double the interval; not re-clamped, so a floored estimate can report a lower bound below 100
    below_floor Bool the raw model output fell below the calibration floor
    route String "v41-ensemble" / "v41-no-maia" / "v2-correspondence"
    serving_path String "exactOpponentMaiaEnsemble" / "neutral1500EvidenceExactArtifact" / "moveQualityFallback"
    accuracy Double 0–100, the mean-loss aggregate (not the Review pane's per-move average)
    sample_moves Int this side's move count

    route and serving_path answer different questions. route names the artifact that served the game; serving_path names the evidence that reached it, and is the raw value of EloEstimatorServingPath:

    Input route serving_path
    correspondence (tc_base_seconds: null) v2-correspondence moveQualityFallback — the v2 lookup never consumes Maia evidence
    typed evidence, exact-lichess-opponent v41-ensemble exactOpponentMaiaEnsemble
    typed evidence, neutral-lichess-1500 v41-ensemble neutral1500EvidenceExactArtifact
    legacy bare maia_log_likes v41-ensemble exactOpponentMaiaEnsemble
    no evidence, or evidence that fails validation v41-no-maia moveQualityFallback

    Evidence fails validation — and silently demotes to the no-Maia ridge — when the vector length is not 11, when any log-like is non-finite, or when typed evidence reports eligible_move_count <= 0.

    Flags¶

    Flag Meaning Default
    --self-test run the golden-parity fixtures and exit without reading stdin off

    That is the only flag. When it is absent the argument list must be empty, or the command errors.

    Decision rules¶

    Time-control class selects the artifact, and a null base is the correspondence signal:

    TimeControlClass.classify(baseSeconds:incrementSeconds:)
    baseSeconds == nil -> .correspondence
    total = baseSeconds + 40 * incrementSeconds
    total <  180 -> .bullet        total < 1500 -> .rapid
    total <  480 -> .blitz         else         -> .classical

    Correspondence has no v4.1 model at all, so estimate falls through to the v2 binned-median lookup on accuracy alone — that is what route: "v2-correspondence" records.

    The interval is built the same way on both branches:

    pointElo     = clamp(rawElo, 100.0, 3500.0)
below_floor  = rawElo < 100.0                     // v4.1 branch
sampleFactor = min(3.0, sqrt(max(1.0, 20.0 / nMoves)))
otbFactor    = is_otb_classical ? 1.5 : 1.0
halfWidth    = baseHalfWidth * sampleFactor * otbFactor

baseHalfWidth
    below floor -> 2.0 * the first residual band's MAE
    otherwise   -> the residual std for pointElo in the serving artifact

    On the v2 branch below_floor means something different: accuracy fell below the lowest binned center and the lookup clamped. The same 2× MAE widening applies.

    Note

    sampleFactor is 1.0 for any game of 20 or more owner moves. A game with fewer than 3 owner moves returns an error rather than an estimate, so on the v4.1 branch the factor reaches at most sqrt(20/3) ≈ 2.58 and the 3.0 cap never binds.

    Errors¶

    An unknown color, an opponent_conditioning string that is not one of the two accepted values, or a nil return from EloEstimator (fewer than 2 evals, or fewer than 3 moves by this side) each emit {"id", "error"} and continue.

    Worked example¶

    printf '%s\n' \
  '{"id":"g1","white_pov_evals":[0,-54.5,-12.0,-140.2,-60.1,-58.0,-210.4,-190.0,-33.0,-40.0,-28.0],"start_is_white":true,"color":"white","tc_base_seconds":300,"tc_increment_seconds":5,"termination":"time forfeit"}' \
  | .build/debug/fianchetto-cli estimate

    The response line carries these keys, alphabetically ordered by the encoder:

    {"accuracy":79.8,"below_floor":false,"ci_high":1833.0,"ci_low":1571.0,"elo":1702.0,"id":"g1","route":"v41-no-maia","sample_moves":30,"serving_path":"moveQualityFallback"}

    (Values are illustrative — the shape and key set are exact.) 300 + 40 × 5 = 500 routes this game through the rapid artifact even though Chess.com would rate it as blitz; see Time-control routing.

    To use Maia evidence, attach the object maia produces:

    {"id":"g1","white_pov_evals":[…],"start_is_white":true,"color":"white","tc_base_seconds":300,"tc_increment_seconds":5,"maia_evidence":{"log_likes":[-15.07,-13.45,-12.56,-12.17,-12.19,-11.36,-11.79,-11.96,-11.93,-12.55,-13.17],"eligible_move_count":3,"opponent_conditioning":"exact-lichess-opponent"}}

    --self-test¶

    --self-test runs eight synthetic fixtures through the same response(for:) function the stream path uses, checks fifteen properties, writes [PASS] / [FAIL] lines to stderr, and exits 0 only if all fifteen pass. Any failure throws, listing the failing check names, and exits 1.

    The fixtures are a port of EloEstimatorGoldenTests.syntheticEvalArray:

    k       = 0.00368208
cpDown  = -ln(100 / (50 - lossPct) - 1) / k
evals[0] = 0;  odd plies = cpDown;  even plies = 0

    All eight are 60 plies, White, start_is_white: true:

    Fixture Clock Loss Extra
    rapid_5pct 600+0 5 % —
    classical_5pct_nomaia 1800+0 5 % —
    classical_5pct_maia_uniform 1800+0 5 % an 11-long vector of -100.0
    blitz_40pct 300+0 40 % —
    classical_5pct_base 5400+30 5 % —
    classical_5pct_otb 5400+30 5 % is_otb_classical
    corr_5pct null / null 5 % —
    rapid_via_increment 300+10 5 % —

    The fifteen checks:

    # Check
    1 rapid elo within 50 of 1702
    2 rapid not below_floor
    3 rapid CI half-width > 50
    4 rapid route is v41-no-maia
    5 classical no-Maia elo within 50 of 1665
    6 uniform-Maia classical elo within 50 of 971
    7 uniform-Maia classical route is v41-ensemble
    8 40 %-loss blitz clamps to within 1.0 of 100
    9 that game is flagged below_floor
    10 that game's CI half-width > 300
    11 OTB / non-OTB CI half-width ratio is 1.5 within 0.01
    12 OTB point estimate is unchanged, within 0.01
    13 correspondence elo within 10 of 1886.75
    14 correspondence route is v2-correspondence
    15 300 + 40 × 10 = 700 routes to rapid: elo and ci_low exactly equal the 600+0 case

    Check 15 is the one that would catch a silent change to the banding rule: two different clocks that must produce bit-identical output.

    Seam provenance¶

    Fully linked. The command calls EloEstimator.estimate(whitePovEvals:startIsWhite:color:tc:isOTBClassical:maiaLogLikes:maiaEvidence:termination:) — the same overload StatsKernel serves from — with TimeControlClass.classify(baseSeconds:incrementSeconds:) for routing and MaiaBackfillPolicy.TargetEvidence / OpponentConditioning for the typed evidence. Nothing is mirrored; the only CLI-original logic is the three-way route label.

    let tc = TimeControlClass.classify(baseSeconds: 300, incrementSeconds: 5)

guard let performance = EloEstimator.estimate(
    whitePovEvals: whitePovEvals,
    startIsWhite: true,
    color: .white,
    tc: tc,
    isOTBClassical: false,
    maiaLogLikes: nil,
    maiaEvidence: MaiaBackfillPolicy.TargetEvidence(
        logLikes: logLikes,
        eligibleMoveCount: 3,
        opponentConditioning: .exactLichess
    ),
    termination: "time forfeit"
) else { return }

performance.elo
performance.ci                 // ClosedRange<Double>
performance.servingPath        // .exactOpponentMaiaEnsemble
performance.belowCalibrationFloor

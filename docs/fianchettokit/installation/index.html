    Installation¶

    FianchettoKit is a Swift Package Manager library that depends on ChessCore.

    Requirements¶

    Minimum
    Swift tools 6.0 (Swift 6 language mode)
    iOS 18.0
    macOS 15.0

    FianchettoKit targets a higher floor than ChessCore (iOS 13 / macOS 10.15) and includes the networking clients.

    Add the package¶

    FianchettoKit pulls in ChessCore transitively, so adding it is all you need:

    // Package.swift
dependencies: [
    .package(path: "../FianchettoKit"),
],
targets: [
    .target(
        name: "Fianchetto",
        dependencies: [
            .product(name: "FianchettoKit", package: "FianchettoKit"),
        ]
    ),
]

    import ChessCore       // Position, MoveGenerator, ...
import FianchettoKit   // the stores, DTOs, network clients — and the JSONBlobStore /
                        // BlobBackedStore storage seam, defined here, not in ChessCore

    Building the API documentation¶

    FianchettoKit ships a DocC catalog and depends on the swift-docc-plugin:

    swift package generate-documentation --target FianchettoKit

    Verifying the install¶

    swift build
swift test

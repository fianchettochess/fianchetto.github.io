    Getting Started¶

    Wire up a storage backend, then load, mutate, and persist a store.

    Provide a blob store¶

    FianchettoKit's stat stores don't talk to disk directly — they read and write through FianchettoKit's own JSONBlobStore seam (see Stores & the storage seam), so you supply the concrete backend (a database, files, the cloud, or just memory). The simplest backend is an in-memory dictionary:

    import FianchettoKit

final class MemoryBlobStore: JSONBlobStore {
    private var storage: [String: String] = [:]
    func loadJSON(forKey key: String) -> String? { storage[key] }
    func saveJSON(_ json: String, forKey key: String) { storage[key] = json }
}

let blobStore = MemoryBlobStore()

    A production backend backs saveJSON with a debounced write into a database row (for example a SwiftData/CloudKit row, or a Room row). The store logic doesn't change with the backend.

    Load, mutate, persist¶

    The Codable stores conform to BlobBackedStore, which gives them load(from:) and save(to:). The mutating record methods persist themselves through the store you pass:

    import FianchettoKit

// Tactics Elo — load, record an attempt, get the rating delta back.
var ratings = TacticsRatingStore.load(from: blobStore)
let delta = ratings.recordAttempt(
    puzzleKey: BlunderMasteryStore.key(fen: fen, correctSAN: "Qxh7#"),
    difficulty: .hard,
    outcome: .correct,        // .correct | .wrong | .skipped
    in: blobStore
)
print(ratings.displayUserRating, "(\(delta >= 0 ? "+" : "")\(Int(delta)))")
print(ratings.peakUserRating)

    // Per-attempt performance history (accuracy, streaks, timing).
var perf = TacticsPerformanceStore.load(from: blobStore)
perf.record(
    TacticsAttempt(
        puzzleKey: BlunderMasteryStore.key(fen: fen, correctSAN: "Qxh7#"),
        outcome: .correct,
        elapsedSeconds: 8.4,
        attemptOrdinal: 1,
        extractionMode: "punish",
        difficulty: "hard"
    ),
    in: blobStore
)
print(perf.accuracy, perf.currentStreak, perf.bestStreak)

    The shared key-format contract¶

    Every store that quizzes the user from a flagged position shares one identity string, "<fen>:<correctSAN>". Always build it with BlunderMasteryStore.key(fen:correctSAN:) so the Elo store, the performance store, and the spaced-repetition counter all line up:

    let key = BlunderMasteryStore.key(fen: position.fen, correctSAN: "Nf6+")

    FianchettoKit¶

    Chess training and analysis logic — engine annotation and Maia, Elo strength estimation, drills and SRS, endgame and combination mining, repertoire gap analysis, library storage and backup, the authored mutation journal, network clients, e-board integration, and voice input — built on ChessCore.

    FianchettoKit depends one-way on the ChessCore package and targets iOS 18 / macOS 15, so it is free to use newer APIs and the networking stack.

    What's inside¶

    FianchettoKit started as three areas — stat stores, persistence DTOs, and network clients — and has grown into the whole of Fianchetto's differentiated chess logic. Almost everything below imports only Foundation and ChessCore and runs with no UI framework attached; a separate fianchetto-cli tool exposes several of these seams headlessly (annotation, Elo estimation, Maia scoring, accuracy, and more) for exactly that reason.

    A quick taste¶

    import ChessCore
import FianchettoKit

// Record a tactics attempt against the Elo store (persisted via the seam).
var ratings = TacticsRatingStore.load(from: blobStore)
let delta = ratings.recordAttempt(
    puzzleKey: BlunderMasteryStore.key(fen: fen, correctSAN: "Qxh7"),
    difficulty: .medium,
    outcome: .correct,
    in: blobStore
)
print("rating \(delta >= 0 ? "+" : "")\(Int(delta))")   // "+12"

// Probe the Lichess tablebase for a 7-man endgame.
let result = try await TablebaseService.shared.probe(fen: endgameFEN)
print(result.category, result.bestMove ?? "—")
